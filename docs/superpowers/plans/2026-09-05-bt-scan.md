# ESP32 BT 双模扫描实施计划（M10 / 蓝牙方向第二步）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ESP32 (board_a) 跑 BR/EDR + BLE 双模扫描，看到飞智八爪鱼5 蓝牙模式在双侧广播。

**Architecture:** 从 ESP-IDF `examples/bluetooth/esp_hid_host/` cp -r 进 `apps/bt_scan/`，删掉自动连接 + state machine，保留 `esp_hid_gap_init(ESP_BT_MODE_BTDM)` + 循环 `esp_hid_scan(5s)`，自定义 `printf` 输出（一行一条，mode/addr/name/cod/rssi）。Tools 不动（`build.py --app bt_scan` / `burn.py --app bt_scan` / `capture_uart.py --board-a` 沿用 M9）。

**Tech Stack:** ESP-IDF v6.0.2, BluedR（`ESP_BT_MODE_BTDM`）, `esp_hid` 组件, `bt_scan` app, board_a（2MB flash, 单 app 大分区）。

**Spec:** `docs/superpowers/specs/2026-09-05-bt-scan-design.md`

## Global Constraints

- **Non-invasive build**: ESP-IDF `/opt/esp-idf` is read-only. Example at `/opt/esp-idf/examples/bluetooth/esp_hid_host/` is read-only; copy then modify the copy in `apps/bt_scan/`.
- **Target chip**: ESP32 (Xtensa LX6, original). `CONFIG_IDF_TARGET="esp32"` pinned in `sdkconfig.defaults`.
- **Build output**: `bluetooth/esp32-wroom-32e/build/bt_scan/` (top-level under board), via `idf.py -B ../../build/bt_scan`.
- **Bluetooth stack**: BluedR (`ESP_BT_MODE_BTDM` = dual-mode). NOT NimBLE (NimBLE is BLE-only and would lose BR/EDR).
- **No auto-connect**: M10 only scans. Do NOT call `esp_hid_host_open()` or any connect API. Avoid polluting controller state.
- **Output**: `printf` plain text, one line per hit. No TLV formatter (M11+).
- **`.env` (top-level, not committed)**: no new keys; ESP32 reuses `BOARD_A_PORT` / `BOARD_B_PORT` / `CTRL_PIN`.
- **Tools**: M9 `tools/{build,burn}.py` already support `--app <name>`; M10 uses `--app bt_scan`, **no changes to tools**.
- **`tools/capture_uart.py`**: top-level (M9 walk-up); CLI unchanged.
- **Board**: only board_a runs M10; board_b kept on `hello_world` (avoid two-board concurrent changes).
- **Code style**: C uses `.clang-format` (LLVM, 4-space, 100 col). No `(void)arg`. No Chinese in code/comments.
- **No placeholders, no TBD**: every step contains the exact content (commands, file paths, expected outputs).

```c
/*
 * SPDX-FileCopyrightText: 2026 flydigi-receiver
 *
 * SPDX-License-Identifier: CC0-1.0
 *
 * bt_scan: continuous BR/EDR + BLE dual-mode scan (M10).
 * Adapted from ESP-IDF examples/bluetooth/esp_hid_host; auto-connect
 * and state machine stripped; only esp_hid_scan loop + printf remain.
 */

#include <stdio.h>
#include <string.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_err.h"
#include "esp_log.h"
#include "nvs_flash.h"
#include "esp_bt.h"
#include "esp_hid_gap.h"

#define TAG                 "bt_scan"
#define SCAN_DURATION_SEC   5
#define SCAN_GAP_MS         500

static void print_scan_results(esp_hid_scan_result_t *results, size_t n)
{
    for (size_t i = 0; i < n; i++) {
        esp_hid_scan_result_t *r = &results[i];
        const char *mode = (r->transport == ESP_HID_TRANSPORT_BLE)
                           ? "BLE" : "BR_EDR";
        const char *name = (r->name && r->name[0]) ? r->name : "";
        /* COD is meaningful only for BR/EDR; BLE usually 0. */
        printf("[bt_scan] mode=%-5s addr=%02x:%02x:%02x:%02x:%02x:%02x "
               "name=\"%s\" cod=0x%06x rssi=%d\n",
               mode,
               r->bda[0], r->bda[1], r->bda[2],
               r->bda[3], r->bda[4], r->bda[5],
               name, (unsigned)r->cod, r->rssi);
    }
}

void app_main(void)
{
    esp_err_t ret = nvs_flash_init();
    if (ret == ESP_ERR_NVS_NO_FREE_PAGES ||
        ret == ESP_ERR_NVS_NEW_VERSION_FOUND) {
        ESP_ERROR_CHECK(nvs_flash_erase());
        ret = nvs_flash_init();
    }
    ESP_ERROR_CHECK(ret);

    ESP_ERROR_CHECK(esp_hid_gap_init(ESP_BT_MODE_BTDM));
    ESP_LOGI(TAG, "ESP_HID_GAP initialized in dual mode (BR/EDR + BLE)");

    while (1) {
        esp_hid_scan_result_t *results = NULL;
        size_t num_results = 0;

        esp_err_t scan_ret = esp_hid_scan(SCAN_DURATION_SEC,
                                          &num_results, &results);
        if (scan_ret != ESP_OK) {
            ESP_LOGE(TAG, "esp_hid_scan failed: %s",
                     esp_err_to_name(scan_ret));
            vTaskDelay(pdMS_TO_TICKS(2000));
            continue;
        }

        if (num_results > 0) {
            print_scan_results(results, num_results);
        }

        esp_hid_scan_results_free(results);
        vTaskDelay(pdMS_TO_TICKS(SCAN_GAP_MS));
    }
}
```

- **手柄需人工切 BT 模式**：背面拨到中间 + 长按配对键（蓝色 LED 亮起进入配对）。M10 不是纯软件测试。
